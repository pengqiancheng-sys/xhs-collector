# 前程-灵感素材库

> 一个 Chrome 浏览器插件：把小红书、YouTube 或任意网页上的**标题、正文、图片、互动数据**一键收藏进你自己的**飞书多维表格**。
>
> 适合做选题库、素材库、竞品观察库——顺手一存，自动归档，不用复制粘贴。

**当前版本：v4.1.0** ｜ 许可：MIT

## 它解决什么问题

你刷小红书看到好选题、好素材，想存下来。手动做的话：截图 → 打开飞书 → 建行 → 复制标题 → 复制正文 → 存图 → 上传附件 → 填来源链接……一条要一两分钟。

这个插件把它变成**点一下**：

- 正文、标题、作者、标签、发布时间、点赞/收藏/评论数，一次全抓
- 图片自动下载并上传到飞书附件字段
- 直接写进你指定的多维表格，字段随你定义

## 功能一览

| 功能 | 说明 |
|---|---|
| 🔴 小红书收藏 | 读取页面已加载的结构化数据 + DOM 解析，拿到标题、正文、图片、作者、互动数据 |
| ▶️ YouTube 收藏 | 提取标题、频道、描述、缩略图 |
| 🌐 网页收藏 | 任意网页提取标题、描述、来源 |
| 📊 飞书同步 | 文本写入多维表格，图片自动上传到附件字段 |
| 🎛️ 可视化设置 | 在设置页配置自己的飞书应用、表格、字段映射，不用改代码 |
| 🔗 字段映射 | 收藏到的 12 个标准字段可映射到任意多维表格字段，支持「智能自动匹配」 |
| 📋 建表提示词 | 内置一键复制的提示词，交给 AI 帮你把配套多维表格建好 |
| 🚀 博主批量收录 | 在博主主页一键批量收录，自动滚动加载、后台标签页执行、不打扰你浏览 |
| 🖱️ 右键菜单 | 页面上右键即可收藏当前页 / 某个链接 / 某张图片 |
| 📤 配置导入导出 | 团队可共享字段映射模板；导出时自动剔除 App Secret |
| 🆕 版本检查 | 每 6 小时检查一次，有新版本在插件角标上提示 |

**支持的浏览器**：Chrome、Edge 及其他 Chromium 内核浏览器（Manifest V3）。

## 快速开始（三步跑通）

```
① 建好配套的多维表格        → 用设置页里的「📋 建表提示词」交给 AI 建，或照表手工建
② 创建飞书自建应用拿凭证    → APP_ID / APP_SECRET
③ 在插件设置页填进去并测试  → 完成，开始收藏
```

整个过程大约 15 分钟，其中第 ① 步用提示词交给 AI 的话只要 1 分钟。

## 安装

1. 拿到 `前程-灵感素材库-v4.1.0.zip`，**解压到一个固定目录**
   > ⚠️ 不要解压到桌面或下载文件夹——那些地方容易被清理，一删插件就失效了
2. 打开 Chrome → 地址栏输入 `chrome://extensions/`
3. 打开右上角 **「开发者模式」**
4. 点击 **「加载已解压的扩展程序」** → 选择第 1 步解压出来的**文件夹**
5. 浏览器工具栏出现插件图标，点击图标即可打开侧边栏

> **如果之前装过旧版本**：请先在扩展管理页「移除」旧版，再重新加载。因为插件改名会导致扩展 ID 变化，无法原地升级。

## 第一步：建好配套的多维表格

插件需要一张**结构特定**的多维表格才能「零配置」直接写入。

### 推荐做法：交给 AI 建

1. 打开插件设置页 → 切到 **「📋 建表提示词」** 标签
2. 点击 **「📋 复制提示词」**
3. 把提示词整段粘给任意 AI（或发给帮你在飞书里建表的人）
4. 按它给出的步骤操作即可

### 手工建表

照这张表在多维表格里建 14 个字段，**字段名必须完全一致**：

| 字段名 | 类型 | 选项 / 说明 |
|---|---|---|
| 选题标题 | 文本 | 主字段（第一列），不可改成其他类型 |
| 多行文本 | 文本 | 正文，最长写入约 15000 字 |
| 作者/来源 | 文本 | |
| 来源平台 | **单选** | `小红书` / `YouTube` / `网页` |
| 来源链接 | 超链接 | |
| 选题来源 | **单选** | `浏览器收录` / `链接收录` / `图片收录` / `批量收录` |
| 素材图片 | 附件 | |
| 标签 | **多选** | 格式 `#标签`，无需预建选项 |
| 发布时间 | 日期 | 日期格式选 `yyyy/MM/dd HH:mm` |
| 点赞数 | 数字 | 小数位 0 |
| 收藏数 | 数字 | 小数位 0 |
| 评论数 | 数字 | 小数位 0 |
| 状态 | **单选** | `待选题` / `已选题` / `已完成` |
| 优先级 | **单选** | `高` / `中` / `低` |

> ⚠️ **加粗的单选/多选字段，选项必须预先建全。** 如果写入时选项不存在，飞书会报错
> `1254062 SingleSelectFieldConvFail`，数据写不进去。
>
> 字段名如果和上表不一致也能用，只是需要在设置页手工做一次字段映射（或用「智能自动匹配」）。

## 第二步：创建飞书自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/) → **开发者后台** → **创建企业自建应用**
2. 在 **「权限管理」** 里搜索并开通以下权限：

| 用途 | 需要的权限（在后台搜索关键词开通） |
|---|---|
| 列出数据表 | 多维表格 — 查看 |
| 读取字段列表 | 多维表格 — 查看 |
| 新增记录 | 多维表格 — 查看、评论、编辑和管理 |
| 上传图片素材 | 云空间 — 查看、评论、编辑和管理云空间中所有文件 |

> 简单说：**给「多维表格」和「云空间」开通读写权限**。如果只想最小授权，可按上表逐项对照。

3. ⚠️ **开通权限后，必须「创建版本并发布」**——这一步最常被漏掉，不发布权限不会生效，接口会一直返回权限不足。
4. 在 **「凭证与基础信息」** 里复制出：
   - `APP_ID`
   - `APP_SECRET`

> 🔐 `APP_SECRET` 是敏感凭证，不要发到公开群里、不要提交到代码仓库。

## 第三步：在插件里配置并连接

点击插件图标打开侧边栏 → 点右上角 **⚙️** 进入设置页。

### 1. 填凭证（「🔑 飞书凭证」标签）

- **App ID** / **App Secret**：粘贴第二步拿到的凭证
- **多维表格完整地址**：直接把浏览器里的多维表格链接整段粘进来，
  形如 `https://xxx.feishu.cn/base/XXXXXXXX?table=tblYYYYYYYY`

### 2. 读取并选择数据表

- 点 **「📚 读取数据表列表」** → 在「选择数据表」下拉里选中你要写入的那张表
- 点 **「📋 自动探测表格字段」** → 插件会读到你表格里的真实字段

### 3. 做字段映射（「🔗 字段映射」标签）

- 点 **「🪄 智能自动匹配」**，插件会按同义词自动对应
- 逐项检查一遍，确认「收藏到的数据 → 你的表格字段」对应正确
- 如果表是按上面标准结构建的，这里会自动全中，不用改

### 4. 保存并测试

- 点底部 **「💾 保存配置」**
- 回到凭证页点 **「🔍 测试连接」**，看到成功提示就通了

> 💡 **配置可以共享给团队**：点「📤 导出配置」会生成一个 JSON（**不含 App Secret**），
> 别人导入后再自己填一下 Secret 即可，省去手工映射的功夫。

## 日常使用

### 收藏当前页面

1. 打开要收藏的页面（小红书笔记 / YouTube 视频 / 任意网页）
2. 点击插件图标打开侧边栏 → 点 **「📥 收藏当前页面」**
3. 侧边栏会显示进度，成功后飞书表格里就有这条记录了

也可以在页面上**右键 → 收进灵感素材库**。

### 博主批量收录

在**小红书博主主页**（地址形如 `/user/profile/xxx`）打开侧边栏，会出现「博主批量收录」面板：

- **收录数量**：想收多少篇（默认 20）
- **间隔(秒)**：每篇之间的等待时间，网络慢就调大（默认 2 秒）
- 点 **「🚀 开始批量收录博主笔记」**

插件会自动：滚动加载博主主页 → 收集笔记列表 → 用一个**后台标签页**逐篇读取 → 写入飞书。

> 说明：批量收录期间**你当前的标签页不会被打扰**，可以继续做别的事。
> 进度和日志在侧边栏的「任务队列」「执行日志」里实时可见。

### 右键菜单

| 右键位置 | 动作 |
|---|---|
| 页面空白处 | 收藏整个页面 |
| 某个链接 | 收藏这个链接 |
| 某张图片 | 收藏这张图片（图片会进附件字段） |

## 字段说明与映射

插件能抓到的 12 个标准字段：

| 数据键 | 含义 | 建议目标字段类型 |
|---|---|---|
| `title` | 标题 | 文本 |
| `text` | 正文内容 | 多行文本 |
| `author` | 作者 / 来源 | 文本 |
| `platform` | 来源平台 | 单选 |
| `sourceUrl` | 来源链接 | 超链接 |
| `sourceType` | 收录方式 | 单选 |
| `images` | 素材图片 | 附件 |
| `tags` | 标签 | 多选 |
| `publishTime` | 发布时间 | 日期 |
| `interactionLikes` | 点赞数 | 数字 |
| `interactionCollects` | 收藏数 | 数字 |
| `interactionComments` | 评论数 | 数字 |

### 字段类型适配规则

插件会**按你目标字段的类型自动转换格式**，不用你操心：

| 目标字段类型 | 插件写入格式 |
|---|---|
| 文本 / 多行文本 | 字符串（正文自动截断到 15000 字） |
| 单选 | 选项名文本（**选项必须已存在**，否则报 1254062） |
| 多选 | 字符串数组，如 `["#美食", "#穿搭"]` |
| 数字 | 数值（自动把「1.2万」「3k」换算成 `12000` / `3000`） |
| 日期 | 13 位毫秒时间戳 |
| 超链接 | `{ text, link }` 对象 |
| 附件 | `[{ file_token }]` 数组 |

## 给 AI 的建表提示词（完整版）

把下面整段复制，发给任意 AI（或有飞书 API 权限的助手），它会按规格把配套多维表格建好。
插件设置页的「📋 建表提示词」标签里也有同样内容，并带一键复制按钮。

```text
【任务】
请帮我创建一个飞书多维表格（Base），用于接收「前程-灵感素材库」浏览器插件自动写入的素材数据。这张表建好之后，插件应当不需要任何字段映射调整就能直接写入，所以字段名、字段类型、选项内容必须严格按下面的规格执行，一个字都不能改。

【前置信息】
- 如果你有飞书 API 调用能力：请用我提供的 app_id / app_secret，先获取 tenant_access_token，再按飞书开放平台文档调用多维表格接口来创建字段。
- 如果你只能输出方案：请输出一份逐步操作清单（在飞书里点哪里、填什么、选哪个类型），并在最后附上「创建字段」的 API 请求体 JSON，方便我用脚本批量创建。

【要创建的表】
- 多维表格名称：素材库
- 数据表名称：素材收集表
- 数据表第一个字段（主字段）：必须是文本类型，字段名「选题标题」

【字段规格（共 14 个，顺序即为建议顺序）】

1.  选题标题    文本      类型编号 1    作为主字段（第一列），不可改为其他类型
2.  多行文本    文本      类型编号 1    单条最长会写入约 15000 字符，需确认容量足够
3.  作者/来源   文本      类型编号 1
4.  来源平台    单选      类型编号 3    选项见下方【选项清单】，必须全部预建
5.  来源链接    超链接    类型编号 15
6.  选题来源    单选      类型编号 3    选项见下方【选项清单】，必须全部预建
7.  素材图片    附件      类型编号 17
8.  标签        多选      类型编号 4    必须建成多选，插件会写入字符串数组
9.  发布时间    日期      类型编号 5    日期格式选 yyyy/MM/dd HH:mm
10. 点赞数      数字      类型编号 2    小数位数设为 0
11. 收藏数      数字      类型编号 2    小数位数设为 0
12. 评论数      数字      类型编号 2    小数位数设为 0
13. 状态        单选      类型编号 3    选项见下方【选项清单】
14. 优先级      单选      类型编号 3    选项见下方【选项清单】

【单选 / 多选字段的选项清单】
注意：这一步是最关键的。多维表格的单选/多选字段在通过 API 写入时，如果传入的值不在预设选项里，会直接报错 1254062 SingleSelectFieldConvFail，写入失败。所以下面每一个选项都必须预先建好，且不得有全角/半角、空格、简写的偏差。

字段「来源平台」（单选），恰好 3 个选项：
  小红书 / YouTube / 网页

字段「选题来源」（单选），恰好 4 个选项：
  浏览器收录 / 链接收录 / 图片收录 / 批量收录

字段「状态」（单选），恰好 3 个选项：
  待选题 / 已选题 / 已完成

字段「优先级」（单选），恰好 3 个选项：
  高 / 中 / 低

字段「标签」（多选）：不需要预建选项，插件写入的是形如 #美食、#穿搭 的字符串数组，允许自动扩展。

【写入数据格式要求（供你校验字段类型是否正确）】
建完字段后，请确认这张表能接受下面这种结构的数据：

{
  "选题标题": "秋冬穿搭公式，普通人也能穿出高级感",
  "多行文本": "笔记正文内容……（最长 15000 字符）",
  "作者/来源": "某某穿搭博主",
  "来源平台": "小红书",
  "来源链接": { "text": "秋冬穿搭公式…", "link": "https://www.xiaohongshu.com/explore/xxxxx" },
  "选题来源": "浏览器收录",
  "素材图片": [{ "file_token": "boxcnXXXXXX" }],
  "标签": ["#秋冬穿搭", "#显瘦"],
  "发布时间": 1761840000000,
  "点赞数": 12800,
  "收藏数": 3400,
  "评论数": 256,
  "状态": "待选题",
  "优先级": "中"
}

关键点：
1. 「来源链接」是超链接字段，写入格式必须是 {"text": "显示文字", "link": "完整URL"} 的对象，不能只传字符串。
2. 「发布时间」是日期字段，写入格式必须是 13 位毫秒时间戳（例如 1761840000000），不能传 "2026-01-01" 这种字符串。
3. 「素材图片」是附件字段，写入格式必须是 [{"file_token": "..."}] 数组，且 file_token 需要先用飞书的素材上传接口上传后才能拿到。
4. 「标签」是多选字段，写入格式是字符串数组；如果误建成文本字段，插件会把标签拼成 "#a, #b" 的一个字符串写进去，能写但不好用。
5. 「点赞数 / 收藏数 / 评论数」是数字字段，写入格式是数值类型，不能带「万」「+」等单位（插件已自动换算成纯数字）。

【另外需要完成的配置：飞书应用权限】
请告诉我在飞书开放平台的「权限管理」里需要开通哪些权限。本插件实际会调用以下 5 个接口，请按最小必要原则逐条对照给出对应的权限名称：

- 获取应用凭证    POST /open-apis/auth/v3/tenant_access_token/internal
- 列出数据表      GET  /open-apis/bitable/v1/apps/{app_token}/tables
- 读取字段列表    GET  /open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/fields
- 新增记录        POST /open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/records
- 上传图片素材    POST /open-apis/drive/v1/medias/upload_prepare / upload_part / upload_finish

特别注意：开完权限后必须「创建版本并发布」，权限才会真正生效——这一步最常被漏掉，会导致接口一直返回权限不足。

【还需要提取给我的信息】
搭好之后，请把下面三项整理给我（插件设置页要用）：
1. APP_ID
2. APP_SECRET
3. 多维表格的完整链接（形如 https://xxx.feishu.cn/base/xxxxxxxx?table=tblxxxxxxxx ）——插件能自动从链接里解析出 APP_TOKEN 和 TABLE_ID

提醒：App Secret 是敏感凭证，不要发到公开群里，也不要提交到代码仓库。插件把它存在本机浏览器里，仅供你个人使用。

【验收标准】请逐条确认：
[ ] 数据表共 14 个字段，字段名与顺序与规格表完全一致（无错别字、无多余空格）
[ ] 「选题标题」是主字段且为文本类型
[ ] 「来源平台」单选已预建 3 个选项，「选题来源」4 个，「状态」3 个，「优先级」3 个，选项文字与规格逐字一致
[ ] 「标签」是多选字段（不是文本、不是单选）
[ ] 「发布时间」是日期字段，格式为 yyyy/MM/dd HH:mm
[ ] 「点赞数」「收藏数」「评论数」是数字字段，小数位 0
[ ] 「来源链接」是超链接字段，「素材图片」是附件字段
[ ] 飞书应用已开通所需权限并已发布版本
[ ] 已把 APP_ID、APP_SECRET、多维表格完整链接提供给我

【补充说明：为什么字段名不能改】
插件内置了一套默认字段映射，正是上表这 14 个名字。字段名对得上，插件装好填完凭证就能直接用；如果对不上，需要在插件的「设置 → 字段映射」里手动逐项选择，或者点「智能自动匹配」让它按同义词猜（能识别「标题/正文/作者/平台/链接/图片/标签/发布时间/点赞/收藏/评论」等叫法）。
所以：严格按规格建 = 零配置可用；自己改名字 = 需要额外做一次映射。
```

## 常见问题

### 写入报错 `1254062` / `SingleSelectFieldConvFail`

单选或多选字段的**选项不存在**。检查：

- 「来源平台」是否有 `小红书`、`YouTube`、`网页` 三个选项
- 「选题来源」是否有 `浏览器收录`、`链接收录`、`图片收录`、`批量收录` 四个选项
- 「状态」是否有 `待选题`、`已选题`、`已完成`；「优先级」是否有 `高`、`中`、`低`

选项文字必须**逐字一致**，全角/半角、多余空格都会导致失败。

### 提示「权限不足」/ `Permission denied`

飞书应用权限**没有发布版本**。回开放平台「版本管理与发布」创建一个版本并发布，权限才会生效。

### 提示「请先配置飞书应用凭证」

设置页的凭证或表格信息没填全，或者点了「测试连接」但没保存。检查：App ID、App Secret、多维表格链接、数据表是否都选好了。

### 收藏成功但正文是空的

页面可能还没加载完。等页面正文显示出来再点收藏。如果反复出现，在「🎛️ 收藏设置」里确认 **「页面数据读取」** 和 **「页面信息解析」** 两个开关都是打开的。

### 图片没上传 / 附件字段是空的

- 确认「🎛️ 收藏设置」里 **「图片同步」** 是打开的
- 检查「最多上传图片数」是不是设得太小
- 图片是逐张串行上传的，图多会慢一些，耐心等进度走完

### 批量收录很慢

正常。默认每篇间隔 2 秒 + 页面加载时间。想快一点就把「间隔(秒)」调小（不要低于 1 秒，容易被限流）。**收录 30 篇大约需要 2 分钟。**

### 表格里出现重复记录

插件目前**不做跨次去重**——同一篇笔记收藏两次就会有两行。建议：

- 收藏前先在表格里搜一下来源链接
- 或在多维表格里加一个「自动化」，按「来源链接」做去重删除

### 收藏不了某些网站

部分网站有严格的反自动化限制，或页面结构特殊导致提取不到内容。换用右键菜单「收藏这个链接」可以至少把 URL 存进去。

### 装了新版本后插件消失了

改过名字的版本扩展 ID 会变，**需要重新加载**。去 `chrome://extensions/` 把旧的移除，重新「加载已解压的扩展程序」。

### 怎么确认用的是最新版

设置页「ℹ️ 关于」标签里有版本号。插件每 6 小时自动检查一次更新，有新版本会在插件图标上显示角标。

## 技术架构

```
浏览器插件 (Manifest V3)
├── manifest.json       扩展清单
├── xhs-bridge.js       注入 MAIN 世界，拦截 fetch/XHR 读取页面结构化数据
├── page-observer.js    DOM 解析 + 页面类型识别（小红书 / YouTube / 网页）
├── page-bridge.js      MAIN 世界 → content script 的消息桥接
├── background.js       Service Worker：任务队列 + 飞书 API 通信 + 字段映射引擎
├── sidepanel.html/js   侧边栏收藏 UI（含博主批量收录）
├── settings.html/js    可视化配置页（含建表提示词 Tab）
├── setup-prompt.txt    建表提示词全文（设置页 fetch 读取）
├── sidepanel.css       侧边栏样式
├── settings.css        设置页样式
├── vendor/md5.min.js   唯一的第三方依赖（本地内置）
├── icons/              图标
├── LICENSE             MIT
└── README.md           本文件
```

**数据流**：

```
页面 → xhs-bridge（MAIN 世界拦截接口响应）
         ↓ postMessage
     page-observer（DOM 解析 + 页面识别）
         ↓ chrome.runtime.sendMessage
     background（任务队列 → 字段映射 → 飞书 API）
         ↓
     飞书多维表格（记录 + 附件）
```

**权限说明**（`manifest.json`）：

| 权限 | 用途 |
|---|---|
| `activeTab` / `tabs` | 读取当前标签页信息 |
| `scripting` | 注入解析脚本 |
| `sidePanel` | 侧边栏 |
| `storage` | 保存配置与凭证 |
| `contextMenus` | 右键菜单 |
| `alarms` | 定时检查更新 |

**第三方依赖**：仅 `vendor/md5.min.js`（用于飞书上传素材的签名计算），已内置，无网络依赖。

## 安全说明

- **App Secret 只存在你本机的浏览器存储里**（`chrome.storage.local`），不会上传到任何第三方服务器。
- **导出配置时自动剔除 App Secret**，导出文件可以安全地分享给同事。
- 开源仓库里**不包含任何真实的 App Secret 或表格 Token**。
- ⚠️ **不要把 App Secret 发给别人。** 拿到它的人可以读写你授权的全部多维表格。
- 本工具用于**个人素材归档与整理**。请遵守你访问的网站的服务条款，并自行确认所收藏内容的合规使用范围。
