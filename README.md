# 前程-灵感素材库 · 浏览器插件

> 把网页上的标题、正文、图片整理进你的飞书多维表格。
> v4.1 起支持自定义飞书应用、自定义多维表格、自定义字段映射，可分享给其他团队使用；仓库不内置任何私有 App Secret 或表格 Token。

## 🚀 功能

| 功能 | 说明 |
|------|------|
| 🔴 小红书收藏 | 页面数据读取 + DOM 深度解析，获取标题、正文、图片、作者、互动数据 |
| ▶️ YouTube 收藏 | 提取标题、频道、描述、缩略图 |
| 🌐 网页收藏 | 自动提取标题、描述、来源 |
| 📊 飞书同步 | 文本写入多维表格，图片上传附件字段 |
| ⚙️ 可视化设置 | 支持配置自己的飞书应用、表格 Token、数据表 ID |
| 🔗 字段映射 | 收藏数据字段可映射到任意多维表格字段 |
| 📋 建表提示词 | 内置一键复制的建表提示词，让 AI 帮你把配套多维表格建好 |
| 🚀 博主批量收录 | 在博主主页一键批量收录笔记（自动滚动加载） |
| 📤 配置导入导出 | 团队可共享字段映射模板；导出时不会包含 App Secret |
| 🆕 版本检查 | 每 6 小时检查新版本，有新版显示 badge 提示 |

## 📦 安装

1. 下载 ZIP 并解压到一个固定目录（不要放桌面/下载，容易误删）
2. Chrome → `chrome://extensions/` → 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」→ 选择解压后的文件夹
4. 点击插件右上角 ⚙️ 进入设置页
5. 如果之前装过旧版本，请先「移除」再重新加载

> 提示：设置页里的「📋 建表提示词」标签可以直接复制一段提示词，交给 AI 帮你把配套的多维表格建好。

## ⚙️ 配置

### 1. 准备飞书应用

在飞书开放平台创建企业自建应用，开启所需权限：

- 多维表格记录读写
- 多维表格字段读取
- 云空间文件/素材上传相关权限

获取：

- `APP_ID`
- `APP_SECRET`

> 注意：不要把包含 App Secret 的配置文件公开分享。

### 2. 配置目标多维表格

在插件设置页填写：

- App ID
- App Secret
- 多维表格完整地址（推荐）
- 或高级模式手动填写 APP_TOKEN / TABLE_ID

然后点击：

1. **自动探测表格字段**
2. **智能自动匹配**
3. 检查字段映射
4. 保存配置
5. 测试连接

### 3. 字段映射

插件收藏到的标准字段：

| 收藏字段 | 含义 | 建议表格字段类型 |
|---|---|---|
| title | 笔记/网页标题 | 文本 |
| text | 正文内容 | 多行文本/文本 |
| author | 作者/来源 | 文本 |
| platform | 来源平台 | 单选/文本 |
| sourceUrl | 来源链接 | 超链接 |
| sourceType | 收录方式 | 单选/文本 |
| images | 素材图片 | 附件 |
| tags | 标签 | 多选/文本 |
| interactionLikes | 点赞数 | 数字 |
| interactionCollects | 收藏数 | 数字 |
| interactionComments | 评论数/评价数 | 数字 |
| publishTime | 发布时间 | 日期/文本 |

> 配套表结构（14 字段、含单选选项）见设置页「📋 建表提示词」，可直接复制交给 AI 建表。

## 🏗️ 技术架构

```
浏览器插件 (MV3)
├── xhs-bridge.js      → 注入 MAIN 世界，拦截 fetch/XHR 读取页面结构化数据
├── page-observer.js   → DOM 解析 + 页面类型识别
├── page-bridge.js     → MAIN → content script 消息桥接
├── background.js      → 任务队列 + 飞书 API 通信 + 字段映射引擎
├── sidepanel.html/js  → 侧边栏收藏 UI
├── settings.html/js   → 可视化配置页（含建表提示词）
└── setup-prompt.txt   → 建表提示词全文（设置页读取展示）
```

## 🔐 安全说明

- App Secret 存储在本地 Chrome storage，仅在本机使用。
- 导出配置时会自动移除 App Secret。
- 开源仓库不应提交真实 App Secret。
